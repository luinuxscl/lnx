# Entrada del proyecto

Lee `README.md`, sección «Trabajo con agentes», para descubrir el mapa del proyecto, las fuentes canónicas y los comandos de verificación. Para cada archivo que cambies, consulta `.ai/rules/index.md` y las reglas aplicables. Usa las skills de `.ai/skills` y las skills instaladas por Boost solo cuando correspondan a la tarea. No des por disponibles plugins personales ni servidores MCP distintos de los configurados en este checkout. Si el proyecto activo define su propio contrato de diseño (por ejemplo, la sección «Contrato visual» de su README o reglas en `.ai/rules`), ese contrato prevalece sobre toda skill global o personal de diseño: úsalas solo donde el contrato calla.
